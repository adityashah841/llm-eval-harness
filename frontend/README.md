# Frontend

React + TypeScript + Vite UI for the LLM Eval Harness API. See the
[main README](../README.md#frontend-vite--react--typescript) for setup, pages and
configuration.

```bash
npm install
cp .env.example .env   # VITE_API_BASE_URL, default http://localhost:8000
npm run dev            # http://localhost:5173
npm run lint           # oxlint
npm run build          # type-check + production bundle
```
